## Research

My research interests include:

- Computational and solid mechanics
- Multiscale and micromechanical modeling
- Molecular dynamics and density functional theory
- Dynamics, vibrations, and nonlinear mechanics
- Smart materials and piezoelectric energy harvesting
- Mechanical and acoustic metamaterials
- Origami- and kirigami-inspired structures
- Multiphysics computational modeling

- **Projects** — selected research and engineering projects
- **CV** — academic curriculum vitae

## Repository structure

The website is built from the al-folio Jekyll theme and deployed automatically through GitHub Actions. The deployment workflow in `.github/workflows/deploy.yml` builds the site and publishes it to GitHub Pages.

> **Note:** This repository is intentionally kept lightweight. The generated website is not stored as raw HTML here; the deployment workflow builds the Jekyll site and publishes the resulting GitHub Pages artifact.
